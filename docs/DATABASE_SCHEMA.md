# Database Schema (v2)

PostgreSQL + **Prisma 7** (pinned; see AUTHENTICATION_DECISION). This is a design specification, not a migration. Concepts are explained in INVENTORY_AND_MANUFACTURING_MODEL.md and PRODUCT_COMPLIANCE_MODEL.md.

## Conventions

- IDs: `cuid2` strings. Every table has `createdAt` / `updatedAt`. Mutable master data has `isActive` instead of being deleted.
- **Customer money:** `Int` paise (prices, order totals, tax amounts, payments). Aggregates in reports use `BigInt`.
- **Quantities:** `Decimal(14,3)` in the StockItem's `baseUnit` (`g`, `ml`, `pcs`). Finished goods are validated as whole numbers.
- **Costs:** `Decimal(14,4)` paise per base unit.
- **Snapshots:** documents (orders, tax documents, batches) copy the master data they used.
- Constraints marked *(SQL)* are added in a raw-SQL migration step because Prisma can't express them.

Legend: **[v1]** built in the first release, **[ERP]** built in a later phase. The schema is designed now so later tables slot in without rework.

## 3. Inventory [v1]

```prisma
model StockItem {
  id String @id
  type            StockItemType   // RAW_MATERIAL | PACKAGING | WIP | FINISHED_GOOD
  code            String @unique  // RM-BHRINGRAJ, PK-BTL-200-AMB, WIP-PHO, FG-PHO-200
  name            String
  baseUnit        String          // g | ml | pcs
  productVariantId String? @unique // only for FINISHED_GOOD  (SQL) CHECK (type='FINISHED_GOOD' OR product_variant_id IS NULL)
  isLotTracked    Boolean @default(true)
  requiresQc      Boolean @default(true)
  reorderLevel    Decimal?
  isActive        Boolean
}

model Warehouse {
  id String @id; code String @unique; name String; address Json
  sellableChannels SalesChannel[]   // which channels may allocate from here
  isActive Boolean
}

model StockLot {
  id String @id; stockItemId String
  lotCode            String           // printed batch number / supplier lot
  supplierLotCode    String?
  mfgDate            DateTime? @db.Date
  expiryDate         DateTime? @db.Date
  qcStatus           LotQcStatus      // QUARANTINE | RELEASED | ON_HOLD | REJECTED
  unitCost           Decimal?         // paise per base unit; null = unknown
  productionBatchId  String?          // set for WIP / FG lots
  goodsReceiptLineId String?          // set for purchased lots [ERP]
  @@unique([stockItemId, lotCode])
}

model InventoryBalance {
  stockItemId String; warehouseId String; lotId String
  onHand   Decimal @default(0)
  reserved Decimal @default(0)
  @@id([stockItemId, warehouseId, lotId])
  // (SQL) CHECK (on_hand >= 0 AND reserved >= 0 AND reserved <= on_hand)
}

model InventoryMovement {           // append-only ledger
  id String @id
  stockItemId String; warehouseId String; lotId String
  quantity    Decimal               // signed
  type        MovementType          // OPENING_BALANCE PURCHASE_RECEIPT PRODUCTION_OUTPUT PRODUCTION_CONSUMPTION SALE
                                    // CUSTOMER_RETURN SUPPLIER_RETURN ADJUSTMENT_GAIN ADJUSTMENT_LOSS DAMAGE
                                    // EXPIRY_WRITE_OFF QC_REJECT TRANSFER_OUT TRANSFER_IN SAMPLE
  reasonCode  String?
  note        String?
  unitCost    Decimal?              // cost carried with the movement
  refType     String                // "SalesOrder" | "ProductionBatch" | "StockTransfer" | "Adjustment" | ...
  refId       String
  reversesId  String?               // correction = reversing movement
  actorId     String?
  occurredAt  DateTime @default(now())
  @@index([stockItemId, warehouseId, occurredAt])
  @@index([refType, refId])
}
// (SQL) REVOKE UPDATE, DELETE ON "InventoryMovement" FROM app_role;

model StockReservation {
  id String @id
  stockItemId String; warehouseId String; lotId String
  quantity  Decimal
  status    ReservationStatus      // ACTIVE | COMMITTED | RELEASED | EXPIRED
  refType   String                 // "SalesOrderLine" | "ProductionOrder"
  refId     String
  expiresAt DateTime?
  @@index([status, expiresAt])
  @@index([refType, refId])
}

model StockTransfer      { id String @id; number String @unique; fromWarehouseId String; toWarehouseId String; status TransferStatus /* DRAFT DISPATCHED RECEIVED CANCELLED */; dispatchedAt DateTime?; receivedAt DateTime? }  // [ERP; table exists in v1 schema]
model StockTransferLine  { id String @id; transferId String; stockItemId String; lotId String; quantity Decimal; receivedQuantity Decimal? }
model AdjustmentReason   { code String @id; label String; direction String /* GAIN|LOSS */; requiresNote Boolean }
```

## 7. Tax documents [v1; rates and HSN pending CA approval]

```prisma
model TaxClass { id String @id; code String @unique; name String; hsnCode String; notes String? }   // entered by owner after CA confirms
model TaxRate  { id String @id; taxClassId String; rateBps Int; effectiveFrom DateTime @db.Date; effectiveTo DateTime? @db.Date; notificationRef String?; approvedBy String? }

model DocumentSeries {
  id String @id
  docType        TaxDocType       // TAX_INVOICE | BILL_OF_SUPPLY | CREDIT_NOTE | DEBIT_NOTE | RECEIPT_VOUCHER
  code           String           // e.g. "WEB", "POS"   (configurable, multiple series allowed)
  financialYear  String           // "2026-27"
  prefix         String           // e.g. "EA/WEB/26-27/"
  nextNumber     Int
  padTo          Int
  isActive       Boolean
  gstin          String           // series belong to a registration
  @@unique([docType, code, financialYear, gstin])
  // (SQL) CHECK (char_length(prefix) + pad_to <= 16)   -- Rule 46(b) 16-character limit
}

model TaxDocument {                 // immutable once ISSUED
  id String @id
  docType       TaxDocType
  seriesId      String
  number        String              // full number, e.g. EA/WEB/26-27/000042
  financialYear String
  status        TaxDocStatus        // ISSUED | CANCELLED   (no DRAFT row consumes a number)
  issuedAt      DateTime
  orderId       String?
  originalDocumentId String?        // credit/debit note → invoice it adjusts
  reason        String?             // credit/debit note reason
  supplierSnapshot Json             // legal name, GSTIN, address, state code
  recipientSnapshot Json            // name, address, GSTIN if B2B, state code
  linesSnapshot Json                // description, HSN, qty, unit, rate, taxable value, CGST/SGST/IGST
  totalsSnapshot Json
  pdfAssetId    String?
  irn String?; ackNo String?; signedQr String?   // e-invoicing, nullable until applicable
  cancelledAt DateTime?; cancelledById String?; cancelReason String?
  @@unique([gstin, financialYear, number])  // gstin denormalised from series
}
// (SQL) trigger: reject UPDATE on TaxDocument except status ISSUED→CANCELLED with cancel fields set.
```

## 10. Invariants

| Invariant | Enforced by |
|---|---|
| Unique SKU / lot per item / batch code / document number per GSTIN+FY | Unique indexes |
| Raw/packaging/WIP never sellable | `productVariantId` only on FINISHED_GOOD (CHECK); allocation filters by type |
| Balance never negative or over-reserved | CHECK constraints + locked conditional updates |
| Balance = Σ ledger | Single write path `inventory.post`; daily drift check (read-only, alerts) |
| Ledger, audit and issued tax documents immutable | DB privileges + trigger |
| Approved formulation versions immutable | Service rule + trigger |
| Batch keeps the recipe it used | `ProductionBatch.formulationVersionId` copied at creation |
| Only eligible lots sold | `inventory.allocate` (INVENTORY_AND_MANUFACTURING_MODEL §4) |
| Webhook processed once | `@@unique([provider, eventId])` |
| Client never sets price or tax | Server recomputes from DB in `sales.priceOrder` |
